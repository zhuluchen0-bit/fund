# 基金净值估算工具 Fund NAV Estimator

基于十大重仓股 + 实时行情，估算开放式基金当日净值涨跌。

## 功能

- 管理基金持仓（添加/编辑/删除）
- 自动获取十大重仓股数据（天天基金）
- 实时股票行情（腾讯行情）
- 加权估算当日涨跌
- 计算持仓每日收益及更新收益率
- 每15秒自动刷新

## 使用

```bash
# macOS 双击启动
./launch.command

# 或命令行
python3 scripts/nav_estimator.py
```

## 数据来源

- 基金持仓: 天天基金网 (东方财富)
- 实时行情: 腾讯行情 API
